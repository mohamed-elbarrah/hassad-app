### Backend API (API)

- [x] **API-01**: `GET /portal/reports` returns composite summary: KPI totals, smart tips, top campaigns list, platform distribution
- [x] **API-02**: `GET /portal/reports/timeline` returns time-series data for bar and line charts, parameterized by `dateFrom`, `dateTo`, `granularity` (week|month|day)
- [x] **API-03**: All aggregate queries are scoped to the authenticated client's `clientId` (server-side derived from JWT)
- [x] **API-04**: KPI card aggregates compute SUM of impressions, clicks, conversions, spend across all client campaigns in selected period
- [x] **API-05**: Period-over-period trend indicators compare current period vs. immediately preceding equivalent period
- [x] **API-06**: Bar chart endpoint groups KPIs by month with Arabic month labels (يناير–ديسمبر)
- [x] **API-07**: Line chart endpoint groups KPIs by week or day based on granularity parameter
- [x] **API-08**: Donut chart endpoint groups spend by `campaign.platform` (Google, Meta, TikTok, etc.)
- [x] **API-09**: Top performers table query returns campaigns sorted by selected metric with campaign name, platform, spend, impressions, clicks, conversions, conversion rate
- [x] **API-10**: Smart tips generated server-side using rule-based heuristics on aggregated data (4 tips max)
- [x] **API-11**: Batch snapshot queries avoid N+1 — use `campaignId IN (...)` pattern
- [x] **API-12**: Empty-state response returns well-formed zero-value shapes (not 404) when client has no campaigns

## Out of Scope (unchanged from original)

| Feature | Reason |
|---------|--------|
| Real-time/live chart updates | Marketing KPIs change daily, not by the second |
| Data editing in dashboard | Read-only view; editing belongs in campaign detail page |
| Cross-client comparison | Violates tenant isolation |
| Drill-down to ad-group/keyword level | Requires ad platform APIs (Meta, Google) |
| Multi-currency display | SAR only |
| Advanced chart types (funnel, cohort, retention) | Overkill for current scope |
| Granular user-level portal permissions | Single client role is sufficient |
